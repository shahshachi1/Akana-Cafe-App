# Akana-Cafe-App
Akana Cafe is a React Native (Expo) mobile app built for a cafe ordering workflow. It handles ingredient-based price calculation, extras and inventory logic, and custom drink orders, with a PocketBase backend. UI includes an animated login drawer and a legibility-focused design pass across screens.

Because I want to keep the actual repo private, please go to this link to access the repo: https://git.popat.org/shachishah/akana-cafe
